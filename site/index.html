Chrome Extension · Gmail API

현재 웹페이지 링크를
한 번의 클릭으로 Gmail에 전송

현재 보고 있는 탭의 제목과 URL을 미리 지정한 Gmail 주소로 전송합니다. 메일 작성창을 열지 않고, 사용자가 승인한 Google 계정으로 Gmail API를 통해 직접 발송합니다.

GitHub 소스 보기 설치 가이드

주요 기능

🔗 현재 탭 링크 공유

현재 페이지의 제목과 URL을 메일로 전달합니다. 사용자 동작 없이 주기적으로 페이지를 수집하지 않습니다.

📨 고정 Gmail 수신자

옵션 화면에서 설정한 Gmail 주소로 자동 발송합니다. 메일 작성 창은 열지 않습니다.

🔐 제한된 Google 권한

Gmail 발송 권한(gmail.send)만 요청하며 받은편지함 읽기 및 삭제 권한은 요청하지 않습니다.

사용 방법

  1. GitHub에서 Quick Link Mail 소스를 받아 Chrome 확장 프로그램으로 로드합니다.
  2. Google Cloud에서 Chrome 확장 프로그램용 OAuth 클라이언트를 설정합니다.
  3. 옵션 화면에서 Gmail 수신자 주소를 저장하고 발신 Google 계정을 인증합니다.
  4. 일반 웹페이지에서 확장 프로그램 아이콘을 클릭합니다.

Chrome 설치와 Google OAuth 설정 방법은 설치 문서를 확인하세요.

개인용 도구 안내: 계정 비밀번호를 요청하지 않습니다. URL에 접속 토큰 등 민감한 정보가 포함된 경우 해당 URL을 보내지 마세요. 발송은 Gmail API의 접수 결과를 기준으로 표시되며 수신함 도착까지 보장하지 않습니다.
