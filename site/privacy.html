적용 대상: Quick Link Mail Chrome 확장 프로그램 및 본 안내 웹사이트
최종 개정: 2026년 10월 16일

1. 서비스와 처리 목적

Quick Link Mail은 사용자가 아이콘을 클릭하면 현재 Chrome 탭의 페이지 제목과 URL을 지정한 수신 Gmail 주소로 보내는 개인용 확장 프로그램입니다. 사용자가 명시적으로 요청한 이메일 전송을 위해 필요한 정보만 처리합니다.

2. 처리하는 정보

  • 현재 탭의 제목 및 URL: 아이콘 클릭 시 조회하여 이메일 본문·제목을 작성합니다. URL의 쿼리 문자열이 포함될 수 있습니다.
  • 고정 수신 Gmail 주소: 사용자가 옵션에서 직접 설정하며 확장 프로그램 로컬 저장소에 보관합니다.
  • Google OAuth 발송 권한: Gmail API의 gmail.send 권한만 요청합니다. 인증 토큰은 Chrome Identity API가 관리하며 확장 프로그램 소스는 토큰을 별도 서버로 전송하거나 저장하지 않습니다.
  • 최근 발송 결과: 전송 일시, 성공 시 수신자·페이지 제목·URL·Gmail API 메시지 ID, 실패 시 오류 메시지를 확장 프로그램의 로컬 저장소에 보관합니다.

3. 정보 이용 및 제3자 제공

이메일 발송을 위해 Google Gmail API에 사용자가 선택한 메일 내용 및 인증 권한을 전달합니다. 메일은 사용자가 지정한 수신자에게 전달됩니다. 별도의 Quick Link Mail 백엔드 서버에 페이지 제목, URL, OAuth 토큰 또는 메일 내용을 전송하지 않습니다. 개인정보를 광고 목적으로 사용하거나 판매하지 않습니다.

4. 보관 및 삭제

수신자 주소와 마지막 전송 결과는 사용자의 Chrome 확장 프로그램 로컬 저장소에 저장되며, 설정 변경·새 전송·확장 프로그램 삭제 등에 따라 변경 또는 삭제됩니다. 확장 프로그램의 Google 계정 연결 초기화 기능은 Chrome이 캐시한 인증을 초기화하며, Google 계정에서 부여된 접근 권한을 철회하려면 Google 계정의 연결된 앱 보안 설정에서 직접 해제해야 합니다.

5. 홈페이지 접속 정보

본 안내 웹사이트는 정적 페이지이며 사이트 자체에 방문자 추적·분석 스크립트나 광고를 사용하지 않습니다. 웹 서버(Traefik/Nginx 및 Docker)의 일반적인 접속 로그에는 IP 주소, 요청 경로, 시각 등이 운영 설정에 따라 기록될 수 있습니다. 이 정보는 보안과 서비스 운영 목적으로만 취급합니다.

6. 보안 및 Google API 정책

확장 프로그램은 사용자가 선택한 발신 Google 계정을 통해 메일을 보낼 수 있는 최소 범위의 권한만 요청합니다. Google API에서 받은 사용자 데이터의 이용은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다. 받은편지함 읽기·메일 삭제 권한은 요청하지 않습니다.

7. 사용자 선택과 문의

언제든 Chrome 확장 프로그램을 삭제하거나 Google 계정의 앱 접근 권한을 철회할 수 있습니다. 본 프로젝트에 대한 문의 및 개인정보 관련 요청은 GitHub Issues로 접수할 수 있습니다. 공개 이슈에는 Gmail 주소나 인증 토큰 등 민감한 정보를 게시하지 마세요.

8. 방침 변경

확장 프로그램의 개인정보 처리 방식이 변경되면 이 페이지와 GitHub 저장소의 문서를 수정하고 개정 일자를 표시합니다.
